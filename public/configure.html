⚙️ 高级配置

全部为可选项，不填则使用默认值

站点域名变更时可修改，留空使用默认 dongpian20.com
用于 IMDb 解析，留空使用内置 Key。填自己的可避免公共 Key 限流
每行一个线路名，匹配到的线路不显示在播放列表中。
维护建议：运行 node health.js 检测长期 404/402 的线路，填入此处。
站点前端发版后签名校验失败时可修改。留空使用默认值。
获取方式：浏览器 F12 → Network → 任意 /v1 请求 → 查看 x-ai-movie-build-version 头。
配置后可播放官方高清线路（resolve 解析）。
获取方式：浏览器登录站点 → F12 → Application → Cookies → 复制 ai_movie_session 的完整值（必须以 ums_ 或 ums2_ 开头）
有效期约 1 年，失效后重新复制即可。不配置则只能播放 m3u8 采集线路。
只显示勾选的类型，取消勾选可减少目录数量
